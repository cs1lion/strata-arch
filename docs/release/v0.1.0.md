# Strata v0.1.0 发布说明

**状态:** 定稿，随 `v0.1.0` tag 一起发布。许可证已确定为 **MIT OR Apache-2.0（双许可）**，见文末。本文件供评审与第一次使用者阅读；GitHub release 尚未创建，也没有发布预编译二进制，本文件只说明源码 tag `v0.1.0` 的内容与边界。

**写给谁:** 第一次接触 Strata、想快速读懂一个陌生 TypeScript/JavaScript 仓库的开发者。假设你会用命令行，不需要先读源码。

## 这个工具解决什么问题

Strata 把「读陌生仓库」拆成几个可以看的问题：它有哪些模块、分成哪些层、谁依赖谁、从入口到目标符号怎么走、结构随提交怎么变、某两个 commit 之间结构改了什么。

所有解析在本地完成，不上传源码；读取目标仓库时不 checkout、不改工作区。输出既可以是原生桌面窗口，也可以是 JSON（`arch-cli`）。

## 四种模式各能看什么

| 模式 | 命令入口 | 看到的 |
| --- | --- | --- |
| `map` | `arch-view map <repo>` | 模块分层地图、模块框、标签与模块间依赖边。可下钻到符号；`/` 或 `Ctrl/Cmd+F` 搜索模块，`↑/↓` 选择、`Enter` 聚焦、`Esc` 清除；带 `--from/--to` 时搜索禁用 |
| `timeline` | `arch-view timeline <repo>` | 按 first-parent 提交采样的演化时间线：模块数、边、分层带随时间的漂移；可离散播放，缺失刻度会显式提示 |
| `diff` | `arch-view diff <repo> --from <commit> --to <commit>` | 两个 commit 的结构差异：added / removed / modified 三色块，附疑似重命名提示；先开窗显示加载态，可取消 |
| `path` | `arch-view map <repo> --from <入口ID> --to <符号ID>` | 入口到目标的一条最短调用路径；底部面板可逐步播放；`--entries` 列出入口候选 |

需要 JSON 而不是窗口时用 `arch-cli`：`index` / `layers` / `callgraph` / `history` / `path` / `drift`。

窗口行为说明：`map` 首屏默认播放 900ms 的分层揭示，任意交互会立即跳到最终态；需要精确静态画面时用 `--no-reveal`。自动化场景可用 `--auto-close-ms <毫秒>` 定时干净退出。

## 平台支持的真实边界

| 平台 | 构建 | 运行验证 | 证据边界 |
| --- | --- | --- | --- |
| Windows | CI 通过 | CI 窗口冒烟通过 | **完整像素证据**：本机 `eval/pixel-evidence.ps1` 24/24 通过，覆盖加载、失败、diff 三色、淡出、播放、搜索五态。该证据需要可见桌面会话、DPI-aware 抓屏，**不进 CI** |
| Linux | CI 通过（需 xcb / xkbcommon 等系统库） | CI 窗口冒烟通过（`xvfb` + `openbox` + Mesa lavapipe 软件渲染） | 只证明能开窗、出帧、干净退出；**不代表真实 GPU 表现，也不证明画面正确** |
| macOS | CI 通过 | CI（GitHub macOS runner）窗口冒烟通过 | 只证明能开窗、出帧、`--auto-close-ms` 干净退出；**没有像素证据**，不代表真实 Mac 的 GPU/显示器体验 |

## 已知限制

- **大仓 `diff` 约 10 秒**：excalidraw（1328 文件）release 热 diff 实测 median 约 9.8s、p95 约 10.2s。窗口先显示加载态与当前阶段，可随时取消或关闭；5000ms 的优化目标仍判红，结构成本保留（见 ticket 10）。
- **输入期间帧 p95 约 48ms**：excalidraw（802 模块 / 4363 边）连续输入实测 p95 **48.6ms**，未达 33ms 预算；匹配本身 release 中位数 0.034ms，瓶颈是每键整帧重绘。判据未改，改进路线另开票（ticket 21）。
- **输入法（IME）未支持**：搜索只采单个可打印字符，中文/日文等组字输入不保证可用；组字状态下的按键无法区分。
- **macOS 无像素证据**：只有 CI 窗口冒烟，不能据此宣称视觉效果与 Windows 一致。
- **票 12 真人可用性测试未做**：5 人、每题 ≥4/5 的协议与答案 key 已就绪，但尚未执行；因此不要把「陌生仓库 30 分钟内说清调用路径」当作已验证结论。

其他边界：

- 模块搜索只搜模块路径，不搜符号、不搜标签文本。
- `timeline` / `diff` 需要非浅克隆的 git 仓库；无 `.git` 的归档副本不能用于 `timeline`。
- Linux 只在软件渲染下验证过；Windows 的像素证据是本机人工项，不是 CI 门禁。
- 顶层 JSX 位于 `root.render(<...>)` 参数内的入口，当前调用图不产生 `module-toplevel` 的 jsx 边，这类入口无法给出路径（见 ticket 06）。
