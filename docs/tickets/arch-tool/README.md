# arch-tool 票务盘点（2026-11-09 结项）

**范围:** `docs/tickets/arch-tool/` 下 01–21（含 03b）。本表按各票正文现状登记，不重判已有结论，也不把 `done-with-gap` 写成 `done`。读数、复现方式与缺口细节以各票正文为准。

**状态口径:**

- `done`：票内验收项都有读数或行为证据；不因自动化全绿而推断人工项通过。
- `done-with-gap`：主功能完成，但票内仍登记未验证、未达标或未执行项。
- `blocked`：依赖外部条件（真人测试、真实硬件等）尚未执行。
- `proposal-only`：只有方案或占位，无实现、无验收读数。

**自动化程度口径:**

- `自动`：有 CI、可重复测试或脚本守门。
- `人工`：判据依赖真人、可见桌面会话或主观判断。
- `未测`：从未执行，或没有可执行判据。
