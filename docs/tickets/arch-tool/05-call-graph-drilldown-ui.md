# 05: 模块下钻与画布交互

**What to build:** 用户在分层地图上点击模块即可下钻到该模块的符号视图，选中节点显示邻居，能平移、缩放、命中测试与按缩放级别隐藏标签；返回上一层不丢失视图状态。

**Blocked by:** 03（层推断与地图）、04（符号与调用图）

**Status:** ready-for-agent

**固定样本：** `tests/fixtures/callgraph` 与 02 的 excalidraw 样本（同 commit）；另有合成 5k 节点 fixture 用于交互压力。

- [ ] `cargo test -p arch-view --test drilldown` 通过：模拟点击某模块后，符号视图中的符号数等于该模块在 JSON 中的符号数；选中节点后高亮邻居集合与 core 返回的邻居集合一致。
- [ ] 返回上一层后，画布的平移偏移与缩放级别恢复为下钻前的值（状态断言）。
- [ ] 命中测试：在已知节点中心坐标点击选中该节点；在空白处点击清空选择；两处坐标断言均通过。
- [ ] 交互：滚轮缩放与拖拽平移后，视图变换在状态中可读；缩放低于阈值时标签隐藏、恢复后重新出现（LOD 断言）。
- [ ] 合成 5k 节点 fixture 上启动、下钻、返回各一次不崩溃、不超时（单次操作 ≤2s，硬件基线记录）。
- [ ] 离屏截图：**已移交 ticket 11 重新定义，当前未验证**；本票不再以 `Window::render_to_image` 作为验收前提（gpui 0.2.2 无公开离屏导出入口）。下钻前后的结构变化用布局模型断言覆盖。
- [ ] 失败判据：符号数不符、邻居不符、状态未恢复、命中偏移、LOD 不生效、5k 节点崩溃或超时。
- [ ] 自动化状态：交互状态与布局断言自动化（待 `gpui::test` 在本机跑通）；截图能力待 ticket 11 选型，当前未验证。
