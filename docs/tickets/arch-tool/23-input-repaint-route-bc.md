## 阶段 0：重基线（必须先做，未做完不得进路线实现）

1. **命令**
   - `pwsh -File eval/frame-timing.ps1 -Mode search -SearchPrefix "/componentscomponentscomponentscomponentscomponentscomponentscomponentscomponents" -SearchKeyDelayMs 1 -Exe target/release/arch-view.exe -OutJson <每次独立文件>`，连续 3 次独立运行，每次独立计算 p95，同时报 median/min/max。
   - `pwsh -File eval/frame-timing.ps1 -Mode stability`（输入负载口径：交互类场景须驱动相同交互再测，§6.1 第 1 条；若现有 stability 模式仅覆盖 idle-pan，需先扩展输入负载分段，属 `eval/` 改动，独立提交并说明）。
2. **固定样本**：同上；release；三次运行同机同会话环境，原始 JSON 全部归档。
3. **期望读数**：不写预测数字（纪律第 2 节：未实测不写预期值）。产出 = 3 次 p95 + 输入负载噪声地板（段间 std/CV/极差）。
4. **决策规则（用户已批准策略，判据本身不改）**
   - 3 次 p95 最大值 ≤33ms：如实报告「缺口在当前构建下未复现」，**提请用户裁决**是否关闭票 20 C8 缺口登记；不自行改判据、不自行宣布关闭。
   - 任一 p95 >33ms：缺口仍在，进入阶段 C；报告时附噪声包络（§6.1 第 4 条：33ms 为产品目标，单跑通/不过均环境敏感）。
5. **失败判据**：用旧批次读数冒充重基线；只跑 1 次；用 idle-pan 噪声地板冒充输入负载地板；基线达标后未经用户裁决自行关闭 C8。
6. **自动化状态**：本机脚本实测（需可见桌面会话），不进 CI；原始 JSON 归档。

## 阶段 C：输入态降格（基线不达标时先做）

照抄票 21 路线 C 的改动面与判据，不放宽：

1. **命令**：`pwsh -File eval/frame-timing.ps1 -Mode ab`（同进程交替，≥12 段 × 60 帧，分段数与 stability 一致）；分别测「只跳 labels」「跳 edges + labels」两档；`pwsh -File eval/pixel-evidence.ps1`；回归见「共用回归」。
2. **固定样本**：同上；降格复用现有 `STRATA_RENDER_SKIP` 类机制，只在 `SearchMode::Input` 期间生效；面板内显示明确的「输入期间简化显示」标记。
3. **期望读数或行为**
   - 生效判定（§6.1 第 3 条）：`gap > k × (2 × 段间 std / √N)`（默认 k=2）且 gap 方向在绝大多数段一致（符号检验）；gap 用绝对 ms 与相对 % 同时报；比较量为 A/B 各自段中位数之均值。
   - 33ms 作产品目标带噪声包络上报（p95 均值、CV、极差），不作单跑硬门禁。
   - 最终态等价：`Enter` 聚焦后与 `Esc` 清除后各抓一帧，与不降格同状态基线**逐像素 0 差异**；输入态差异只允许出现在声明的降格元素上。
   - 状态隔离：模型断言 `Input` 之外（`Focused`/`Closed`）不得带降格标志；离开输入态同一帧恢复；降格标记只在输入态可见。
4. **失败判据**：为达标把 33ms 改宽或改像素闸门；降格泄漏到聚焦/关闭态；最终态与基线有像素差；标记不可见或文案缺失；收益未达显著性却宣称「有收益」；用两批顺序比较替代同进程交替。
5. **自动化状态**：部分自动化——状态隔离与降格标志的模型断言进 CI；性能与像素为本机人工项。收益不显著 → 如实报「不可判定」并回退实现（票 10 / 票 21 路线 A 先例），不得宣布「无收益」。

## 阶段 B：离屏缓存（C 不达标或不可接受时的备选）

照抄票 21 路线 B 的判据，**可行性前置**：

1. 先证明存在**不改变 `gpui = "=0.2.2"` 与 `--locked`** 的公开 API 路径能缓存所需粒度；证明不了就以「不可行」关闭本路线，附源码检索与最小复现，不得先写实现再解释。
2. 若可行：性能判定同阶段 C（§6.1 显著性 + 33ms 产品目标）；静止帧与无缓存基线逐像素 0 差异；相机/缩放/resize/DPI/主题/下钻/淡出/揭示各失效路径重建后与基线一致；缓存内存/显存峰值有上限并归档读数。
3. 失败判据：破坏版本 pin 或 `--locked`；需要第二条渲染路径却未按票 10「共享场景 IR」约束登记；静止帧有像素差；缓存失效漏判；内存/显存无读数。
