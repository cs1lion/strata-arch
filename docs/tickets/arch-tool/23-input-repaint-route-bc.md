## 阶段 C：输入态降格（基线不达标时先做）

> **执行前必读**：本节第 1 条的 `-Mode ab` 经源码核查与实现不兼容，且档位设计已被 2026-11-16 的配对筛查读数改写。见本节下方「票面更正」与「阶段 C′」两节。本节的判据数值（33ms、显著式、逐像素 0 差、状态隔离）一律不改、不放宽。

照抄票 21 路线 C 的改动面与判据，不放宽：

1. **命令**：`pwsh -File eval/frame-timing.ps1 -Mode ab`（同进程交替，≥12 段 × 60 帧，分段数与 stability 一致）；分别测「只跳 labels」「跳 edges + labels」两档；`pwsh -File eval/pixel-evidence.ps1`；回归见「共用回归」。
2. **固定样本**：同上；降格复用现有 `STRATA_RENDER_SKIP` 类机制，只在 `SearchMode::Input` 期间生效；面板内显示明确的「输入期间简化显示」标记。
3. **期望读数或行为**
   - 生效判定（§6.1 第 3 条）：`gap > k × (2 × 段间 std / √N)`（默认 k=2）且 gap 方向在绝大多数段一致（符号检验）；gap 用绝对 ms 与相对 % 同时报；比较量为 A/B 各自段中位数之均值。
   - 33ms 作产品目标带噪声包络上报（p95 均值、CV、极差），不作单跑硬门禁。
   - 最终态等价：`Enter` 聚焦后与 `Esc` 清除后各抓一帧，与不降格同状态基线**逐像素 0 差异**；输入态差异只允许出现在声明的降格元素上。
   - 状态隔离：模型断言 `Input` 之外（`Focused`/`Closed`）不得带降格标志；离开输入态同一帧恢复；降格标记只在输入态可见。
4. **失败判据**：为达标把 33ms 改宽或改像素闸门；降格泄漏到聚焦/关闭态；最终态与基线有像素差；标记不可见或文案缺失；收益未达显著性却宣称「有收益」；用两批顺序比较替代同进程交替。
5. **自动化状态**：部分自动化——状态隔离与降格标志的模型断言进 CI；性能与像素为本机人工项。收益不显著 → 如实报「不可判定」并回退实现（票 10 / 票 21 路线 A 先例），不得宣布「无收益」。

## 票面更正（2026-11-16，源码与实测取证；不改写上方任何判据与读数）

阶段 C 第 1 条命令写「`-Mode ab`（同进程交替）… 分别测「只跳 labels」「跳 edges + labels」两档」，经源码核查**该命令做不到**：

后果：本票阶段 C 第 4 条失败判据「用两批顺序比较替代同进程交替」在当前实现下**无法履行**——同进程交替的降格 A/B 路线尚不存在。替代口径为 `eval-harness.md` §6.1 第 6 条（配对差），本票读数一律按该口径采集。**第 1 条与第 4 条原文保留不删**，待 `-Mode ab` 扩展出 skip 轮换能力（需产品代码改动 + A 档 Red）后再启用。

附带的取证缺陷：`counters` 行的 `edges=4363` 属**场景对象计数**，只有 `labels` 是绘制计数（`main.rs:3204-3209`），因此不能用它证明 `skip.edges` 未生效——本票此前一处判断据此被更正，详见 §6.1 第 6 条的取证要求。

2. **固定样本**：`tests/corpus/excalidraw`（802 模块 / 4363 边 / 6 层带，`eval/corpus.toml` pin）；release，**测量前核对二进制时间戳晚于最后一次代码改动**；降格只在 `SearchMode::Input` 生效；面板标注「输入期间简化显示」。
3. **期望读数或行为**
   - 显著性：`|mean(gap)| > 2 × (2 × std(gap) / √N)` 且同号 ≥5/6，median 与 p95 **两侧分别判定**；gap 同报绝对 ms 与相对 %。
   - **必须同时报 median 代价**：以 p95 收益结案而隐去 median 代价，视为未交付。
   - 33ms 保留为产品目标带噪声包络上报；按现读数 C′ 单独不足以达标（差 0.82–0.86ms），须与路线 B 或缓存成本解释组合，**不得为此改 33ms**。
   - 最终态等价与状态隔离：沿用阶段 C 第 3 条第 3、4 项判据，不放宽。
4. **失败判据**
   - 只报 p95 收益、不报 median 代价；或把「降格后 p95 33.86ms」写成达标。
   - 为达标改 33ms、改显著式、改像素闸门，或多跑几批只挑显著的那批。
   - 跨批复用段间地板，或拿不同批的 base 与候选档配对（§6.1 第 5、6 条禁止）。
   - `-Skip` 参数形态错误（连字符）却当作 edges 档读数；或无生效证据即宣称「已降格」。
   - 降格泄漏到 `Focused`/`Closed`；最终态与基线有像素差；标记或文案缺失。
   - 未解释 median 为何变慢就实现（机制归因缺失时，收益数字可能来自缓存命中模式变化，而非省下的绘制工作量）。
5. **自动化状态**：部分自动化——状态隔离与降格标志的模型断言进 CI（headless）；配对性能读数与像素证据需可见 Windows 桌面会话，不进 CI，登记 `docs/acceptance-gaps.md`。收益未达显著 → 报「不可判定」，不宣布无收益（同阶段 C 第 5 条）。
