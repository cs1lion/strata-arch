# 07: 路径播放与逐步追光

**What to build:** 用户选定路径后，桌面端沿边播放这条路径：当前边逐步追光、非路径元素淡出，可前进/后退/暂停，可一键关闭动画；关闭后只显示静态完整路径且不再调度动画帧。

**Blocked by:** 05（画布交互）、06（路径查询）

**Status:** ready-for-agent

**固定样本：** 06 冻结的 tsx golden 路径（步骤数固定）；`tests/fixtures/animation` 短路径（3 步）用于帧与开关断言。

- [ ] `cargo test -p arch-view --test path_playback` 通过：播放到第 k 步时高亮集合等于路径前 k 步对应的节点与边；前进/后退/暂停状态断言均通过。
- [ ] 逐步追光：每一步只高亮当前边；非路径节点与边的不透明度低于基线阈值，路径已走过的部分保持可见（状态断言）。
- [ ] 关闭动画（默认关闭，推荐值，**待用户确认**）后：路径仍以静态完整形式可见；测试中动画帧调度计数为 `0`（`request_animation_frame` 埋点断言）。
- [ ] fly-to（镜头移动）默认关闭；开启后镜头中心落在当前步骤节点包围盒内（状态断言）。
- [ ] 帧预算：播放期间记录帧时间，p95 ≤16.7ms（推荐值，**待用户确认**）；在 3 步与 20 步路径上各跑 3 次，读数归档到 `out/frame-timing.json`，含硬件信息。
- [ ] 路径结束后停留在完整路径状态，不自动循环；再次播放从第 1 步开始。
- [ ] 失败判据：高亮与步骤索引不符、关闭后仍有帧调度、p95 超预算且未标为硬件受限、路径结束状态错误。
- [ ] 自动化状态：状态与开关断言自动化；帧时间仅本机归档，不作 CI 硬门禁（依赖硬件与驱动）。
