# 12: 上手会话可用性任务测试

**What to build:** 用一个固定的人工协议验证「陌生仓库 30 分钟内能说清调用路径与所属模块」：5 个任务、答案 key、参与者记录与证据归档，产出可复核的失败清单。

**Blocked by:** 07（路径播放）、09（演化时间线）

**Status:** ready-for-agent

**固定样本：** `privatenumber/tsx` 完整 git clone @ `4473971f4b3261de253209b148d8fdc43269fcc4`；excalidraw 本轮未覆盖。任务与答案 key 由维护者预先写出并冻结。

- [ ] 协议包含 5 个任务：①说出某入口到某目标符号的调用路径与经过的层；②指出窗口内被反复修改最多的 3 个模块并说明依据；③指出多年未动的 2 个模块并说明依据；④指出一次提交里新增/删除/修改了哪些模块；⑤说出被高亮/加粗的边与步进顺序的语义（静态调用关系 vs 数据流/执行顺序）。每个任务附标准答案 key（模块/符号序列与指标区间）。
- [ ] 参与者 5 人（用户 2026-11-08 已确认），均为未接触过样本仓的开发者；每人独立完成，不提示、不互相讨论。
- [ ] 通过阈值：每任务 ≥4/5 参与者答案与 key 一致（用户 2026-11-08 已确认）；同时记录完成耗时（中位数）。
- [ ] 证据归档：`out/usability.json` 含参与者编号（匿名）、任务、是否通过、耗时、误答类型、使用过的视图；原始记录留存可复核。
- [ ] 失败判据：任一任务通过率 <4/5、答案 key 在测试后被修改、耗时超过 30 分钟且未记录、证据缺失。
- [ ] 自动化状态：不可自动化（主观理解需人工）；本票只要求协议与记录可复核。
- [ ] 若未达阈值，产出按视图归因的缺陷清单（地图/下钻/路径/演化），不以「用户不会用」结案。

**交付物（2026-11-08）：** 5 人 / 每题 ≥4/5 已由用户确认；任务扩为 T1–T5（新增 T4 commit 归属、T5 语义误读）。可执行测试包见 `docs/research/usability/README.md`、`facilitator-script.md`、`answer-key.md`、`score-sheet.md`。
