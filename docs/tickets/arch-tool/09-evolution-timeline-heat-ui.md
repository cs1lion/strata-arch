# 09: 演化时间线与模块热力视图

**What to build:** 用户能在桌面端看到一条提交时间线，拖动到某个历史提交时，分层地图上的模块按「热力」呈现该时刻的变更活跃度，并看到该模块的指标面板；演化视图与结构地图使用同一套模块 ID。

**Blocked by:** 03（分层地图）、08（历史采样与指标）

**Status:** ready-for-agent

**固定样本：** `tests/fixtures/history`（5 个提交，期望值可手工算出）与 `excalidraw/excalidraw` @ `701b901a0f1ba3d0b390d9cdf63d112e25abac4b`。

- [ ] 时间线渲染：`cargo run -p arch-view -- timeline <repo> --screenshot out/timeline.png` 退出码 `0`，图像非空（宽高 >0，不同颜色数 >10）；刻度数与扫描提交数一致。
- [ ] 拖动到 fixture 第 k 个提交后，模块 `lastModified` 面板读数等于「截至该提交重新计算」的期望值（fixture 3 个选取模块逐点断言）；不得只显示最新值。
- [ ] 热力映射固定且可解释：churn/commitCount 到颜色/大小的映射函数在测试中冻结；无历史模块显示为中性灰并带标记；图例可见。
- [ ] 共享 ID：演化视图与地图视图中同一模块的 ID 完全一致（集合断言通过）。
- [ ] 状态标记：`sampled`/`truncated`/`shallow` 在视图中有可见标记；标记存在时热力不得表现成全量读数。
- [ ] `cargo test -p arch-view --test timeline_scrub` 通过：刻度切换、模块选择、返回地图后的状态断言。
- [ ] 截图结构断言：**已移交 ticket 11 重新定义，当前未验证**；本票以布局模型与热力映射断言为主，像素差门禁随截图能力一并待定。
- [ ] 失败判据：刻度读数取最新值、热力映射漂移、ID 不一致、状态标记缺失、布局模型中的刻度或节点数与产物不符。
- [ ] 自动化状态：状态与结构断言自动化；像素差与视觉效果依赖硬件基线，暂不进门禁。
- [ ] 动画与探索式交互不在本票范围：播放/回放动画与跨视图联动细化见 ticket 13（占位）。
